## 🏗️ Featured: DigitTwin platform

A set of reusable building blocks for .NET microservices, built around **DDD** and **Clean Architecture**:

| Package | What it does |
|---|---|
| [**DT.Kernel**](https://github.com/YagudinAleksandr/DT.Kernel) | Domain core for DDD — entities, aggregates, value objects, domain events |
| [**DT.Application**](https://github.com/YagudinAleksandr/DT.Application) | Application-layer library: use cases, pipelines, contracts |
| [**DT.SimpleEventBus**](https://github.com/YagudinAleksandr/DT.SimpleEventBus) | Lightweight event bus for in-service messaging |
| [**DT.RedisConnector**](https://github.com/YagudinAleksandr/DT.RedisConnector) | Managing multiple Redis connections from one service |
